# Bài Tập Bổ Sung

Bài tập chính của học viên nằm trong **`docs/sprints/sprint-XX/03-api-tasks.md`** – đây là task board Dev cần hoàn thành.

Thư mục này chứa **bài tập bổ sung** (optional) hoặc challenge nâng cao sau khi hoàn thành task trong Sprint.

---

## Task chính vs Bài tập bổ sung

| Loại | Vị trí | Bắt buộc |
|------|--------|----------|
| **Task chính** | `docs/sprints/sprint-XX/03-api-tasks.md` | ✅ Có |
| **Test verify** | `docs/sprints/sprint-XX/04-test.md` | ✅ Có |
| **Bài tập bổ sung** | `docs/bai-tap/day-XX-bai-tap.md` | Tuỳ chọn |

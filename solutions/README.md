# Đáp Án Bài Tập

Thư mục chứa đáp án cho từng buổi. Giảng viên push đáp án **sau 3–5 ngày** kể từ ngày ra đề.

---

## Cấu trúc

```
solutions/
├── day-01/
├── day-02/
├── ...
└── day-22/
```

Hoặc publish qua Git tag: `solution-day-01`, `solution-day-02`, ...

---

## Quy tắc cho học viên

1. **Tự làm bài trước** khi mở đáp án
2. Đáp án chỉ là **một cách làm**, không phải cách duy nhất
3. So sánh đáp án với code của mình, ghi chú điểm khác biệt
4. Không chia sẻ đáp án ra ngoài khóa học

---

## Quy tắc cho giảng viên

- Mỗi folder `day-XX/` chứa diff hoặc file hoàn chỉnh của phần bài tập
- Ghi README ngắn trong mỗi folder giải thích approach
- Tag `solution-day-XX` trên commit tương ứng
